# Swiftwarm Sports Health — HTML Prototype

هذا المجلد يحتوي نموذج صفحة ويب مستقل مبني على **HTML + Tailwind CSS عبر CDN + JavaScript خام**. الصفحة RTL ومتجاوبة، وتضم الجاهزية اليومية، الاختبارات ذات النتائج، ألعاباً تحفيزية، برامج هدف الجسم، مساعداً ذكياً تجريبياً، وبرنامج النادي الانتخابي.

## الملفات

| الملف | الاستخدام |
|---|---|
| `index.html` | هيكل الصفحة والأقسام والنوافذ التفاعلية |
| `styles.css` | الهوية البصرية والحركات والاستجابة |
| `app.js` | منطق الاختبارات والألعاب والبرامج والمساعد |
| `serve.mjs` | خادم Node صغير للاختبار المحلي فقط |

## التشغيل المحلي

من داخل مجلد المشروع شغّل `node web/serve.mjs` ثم افتح `http://localhost:4173`. في الإنتاج يُفضّل تثبيت Tailwind محلياً عبر Vite أو PostCSS بدلاً من CDN، ورفع الصور إلى تخزين ملفات خلف CDN بدلاً من وضع الوسائط الكبيرة داخل `public`.

## ملاحظات المنتج

النتائج إرشادية وليست تشخيصاً طبياً. يجب ربط المساعد الذكي بخادم آمن قبل استخدامه مع بيانات أعضاء حقيقية، مع موافقة واضحة، تقليل البيانات، وسجل تدقيق. البرنامج الانتخابي في النموذج يعرض رؤية ومشاركة رأي غير ملزمة، وليس نظام تصويت رسمياً.
